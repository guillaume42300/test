# Observateur Basket — application Android native

V1 native Android du projet d'observation d'arbitres.

Fonctions incluses :
- fiche match équipes + arbitres
- dictée vocale Android
- situations par période et catégorie
- terrain interactif avec marqueurs A/B/R déplaçables
- bilans Q1 / mi-temps / Q3 / fin
- validation stricte : 2 à 3 positifs + 2 à 3 pistes de travail par arbitre
- sauvegarde locale sur le téléphone
- génération d'un rapport texte de synthèse

## Ouvrir le projet
1. Installer Android Studio sur un ordinateur.
2. Ouvrir ce dossier comme projet.
3. Laisser Gradle télécharger les dépendances.
4. Brancher le téléphone Android ou utiliser un émulateur.
5. Run > Run 'app'.

## Important
Cette V1 est une application native de travail. La génération réellement "intelligente" du débrief (IA), l'export PDF et les flèches de déplacement sont prévus pour la V2. Une clé API ne doit jamais être intégrée directement dans l'application.
